# Sky – A Minimal Task Manager with Personality

Sky is a lightweight task manager inspired by Duke, enhanced with:

- A unique chatbot personality
- Improved and resizable GUI
- Update command for editing existing tasks
- Clean JavaFX interface

## Personality

Sky is friendly and conversational.

Example responses:
- "Hello! I'm Sky ☁ How can I help you today?"
- "Nice! I've marked this task as done."
- "Oops! Please provide a valid task number."

The UI has also been styled to match Sky's clean, minimal aesthetic.
